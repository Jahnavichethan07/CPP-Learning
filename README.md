1. Linking pipelines: <#include, #define>, linker symbol resolution.
2. Variable & Data Types: Primitive data types, memory footprints (sizeof) and type safety.
3. Functions and Header files: Separating declaration (.hpp) from definition (.cpp) and preventing duplication inclusion using <#pragma once>.
4. Debugging: Two important features i.e Break point and Reading memory.
